# iクラブ 技テストアプリ

## 概要
iクラブの体操・運動指導で使用する技テスト評価アプリ。

## 主な機能
- 生徒名簿
- 当日の班分け
- 技テスト評価入力
- 評価履歴
- 評価比較
- ゲスト登録
- 先生登録・承認
- 管理者管理
- 変更申請
- 操作履歴

## データ保存
Googleスプレッドシート + Google Apps Script

## 共通ID
- 子ども：iC001形式
- 先生：iT001形式
- 校舎：iDA形式など

## 開発方針
- 既存データを壊さない
- 既存IDを変更しない
- 既存WebアプリURLを維持する
- 変更は小さい単位で行う
- 動作確認後に次の工程へ進む

## コード
- Code.gs：GASバックエンド

## 開発管理
- SPEC.md：確定仕様
- DEV_STATUS.md：現在の開発状況
- DECISIONS.md：設計上の決定事項
